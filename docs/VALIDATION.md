## 保留的场景证据

此前在独立上下文进行了离线场景演练；本轮只保留其范围与结论，不将旧包装检查当作新版本验证：

| 场景 | 演练结果 | 未验证范围 |
| --- | --- | --- |
| 无云端账号、SDK／UI 尚未安装 | 可先规划与完成独立本地工作；后续阶段缺 Key 不成为全局阻塞 | 未真实安装或创建应用预览 |
| 原生认证＋BFF HTTP PG、员工未接受邀请 | 不要求未采用的 CAM／签票／直连凭据；Agent 执行受阻，部署按自身门禁判断 | 未验证真实认证、注入或开通 |
| 并行分支受理未知且要求重跑、升级和取消 | 核对原请求，不盲目重发；在途保留原快照，取消逐节点确认 | 未实现或运行真实编排 |
| 新会话接手未提交认证更改、检查报告属于旧版本 | 保留改动，核对事实并重跑受影响阶段，不直接发布或重放副作用 | 未运行目标应用回归 |
| 缺私有 UI 权限、机器有其他客户环境 | 不继承其他客户资源，不把 Partner Key 给浏览器，不暗换组件库 | 未取得 UI 私有包或访问客户配置 |

## 明确的验证边界

本仓库检查只验证文档结构、链接和模板；不提供通用自动开发执行器或可直接部署的 SaaS。生成应用仍须实现配置读取、doctor、权限、任务与业务流程，并分别完成构建、回归、浏览器、云端和真实模型验收。

本轮不重新宣称所有第三方官方链接在线可达；实际接入前核对当前官方文档、SDK 类型与权限。私有 GitHub 链接需要账号权限，匿名网页抓取不作为私有文档可读性的依据。
